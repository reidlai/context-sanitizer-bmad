The Converged 3-Tier Speculative Cascade

Lens 2: TRIZ Contradiction Resolution

Tier 1 (L0): Pure-Rust SIMD & AST Guard

< 0.5 ms • 0 MB Weights • Always On
  • Copilot UI / OpenAI API Boundary: Intercepts malicious code injections & user PII before hitting the agent framework.
  • Two-Way Ephemeral Shadow Vault: Swaps PII/secrets into a Rust DashMap with TTL so cloud LLMs never see raw PII, then rehydrates values locally for tool calls.
  • tree-sitter AST Lock: Locks code & JSON syntax tokens so pruning never corrupts valid code.

Tier 2 (L0.5): Pure-Rust Smart Statistical Pruning

< 2.0 ms • 0 MB Weights • Always On
  • Zero-Download Out-of-the-Box: cargo add context-sanitizer delivers 40–60% compression immediately with zero neural weights.
  • Information-Theoretic Scoring: Uses tiktoken-rs + query-aware BM25, TF-IDF, and self-information entropy $I(x) = -\log P(x)$.
  • JSON Tool Schema Minifier: Strips bloated MCP & OpenAI tools[] descriptions in-flight.

Tier 3 (L1): Shared-Backbone System One ML

Opt-in (--features ml) • Int8 Quantized (~45 MB)
  • One Forward Pass, Three Heads: Runs DeBERTa-v3 / ModernBERT in Rust (candle / ort).
  • [CLS] Head: Blocks semantic IP leaks, prompt injections, & routes payloads.
  • Token Heads (LLMLingua-2): Computes token-level $p(\text{keep})$ and surgically excises adversarial spans.
