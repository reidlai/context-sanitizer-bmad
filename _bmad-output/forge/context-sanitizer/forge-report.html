BMad Forge Idea • Pressure-Test Report

context-sanitizer

3-Tier Rust & System One LLM Firewall, Session-Scoped Shadow Vault, and Hard Token Compressor. Four critical architectural cracks were exposed, cross-examined, and resolved into hardened engineering decisions.

Locked Decisions (What Survived & Hardened)

Locked #1

Sequential Off-the-Shelf Tier 3 Pipeline

Tier 3 (--features ml) uses real, off-the-shelf Hugging Face checkpoints sequentially: the System One security gatekeeper runs first and short-circuits on threats; LLMLingua-2 token pruning runs second only on safe inputs.

Locked #2

Trait-Based Configurable Model Swapping

Public Rust traits (pub trait SemanticGuard & pub trait TokenCompressor) plus configurable guard_model_id / compression_model_id (defaulting to DeBERTa-v3 Zero-Shot NLI + L0 custom terms, and LLMLingua-2 BERT) let users swap models anytime.

Locked #3

Session-Scoped Shadow Vault + Split Secret Policy

Uses cryptographic session tokens (<SHADOW:EMAIL_8f3a2c>) + .rehydrate() API. Operational PII is vaulted two-way for tool calls; root secrets (AWS keys, PATs) default to one-way [REDACTED_*] to prevent indirect prompt-injection exfiltration.

Locked #4

100% Pure-Rust Lexical Scanner & 3-Crate Workspace

Uses pure-Rust lexical/JSON scanning (logos + serde_json) for syntax locking & code-injection checks, organized into context-sanitizer, context-sanitizer-cli (xray), and context-sanitizer-py.

Killed Assumptions (What Was Rejected & Why)

Killed #1

Single Shared-Backbone Multi-Head Checkpoint

Rejected because off-the-shelf Prompt Guard and LLMLingua-2 checkpoints use separate architectures and tokenizers, and training custom weights is a distraction from the Rust systems showcase.

Killed #2

Global Predictable Vault Counter (EMAIL_1) & Root-Key Rehydration

Rejected because sequential global IDs allow cross-tenant prompt-injection theft, and rehydrating root credentials into tool arguments allows attackers to exfiltrate keys.

Killed #3

C-Based tree-sitter Grammar Compilation

Rejected because compiling multiple C/C++ language grammars bloats build times and causes cross-platform C-linker failures during maturin Python wheel builds.
