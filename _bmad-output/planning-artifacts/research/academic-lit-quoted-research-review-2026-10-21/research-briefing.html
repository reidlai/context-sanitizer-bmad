Executive Summary

Verdict: The architectural core of context-sanitizer is strongly grounded in peer-reviewed research (9 Verified), but 3 load-bearing claims in README.md are overturned (3 Overturned) by primary-source and authenticated Hugging Face Hub checks and should be fixed before writing SPEC.md:

  1. Overturned (HTTP 404) guard_model_id in README.md (Lines 117, 177, 248, 325): MoritzLaurer/DeBERTa-v3-xsmall-mnli-fever-anli-ling-wanli returns HTTP 404 Not Found on Hugging Face Hub [10]. The -wanli suffix exists only on large (MoritzLaurer/DeBERTa-v3-large-mnli-fever-anli-ling-wanli). Valid checkpoints built on microsoft/deberta-v3-base / xsmall [7] are MoritzLaurer/DeBERTa-v3-base-mnli-fever-anli (467k downloads), MoritzLaurer/deberta-v3-xsmall-zeroshot-v1.1-all-33 (42.9k downloads), and MoritzLaurer/DeBERTa-v3-xsmall-mnli-fever-anli-ling-binary [10].
  2. Overturned Attribution Tier 2 Zero-Weight Attribution to Selective Context & RECOMP (README.md Line 48): Selective Context (Li et al., EMNLP 2023) requires a causal LM (GPT-2/OPT/LLaMA) to compute conditional self-information $I(x_t) = -\log_2 P(x_t \mid x_{<t})$ [4], and RECOMP (Xu et al., ICLR 2024) trains neural dual-encoder and T5-Large compressors rather than submodular functions [5]. Tier 2's 0-weight engine is inspired by them, while its actual 0-weight math rests on static unigram self-information/IDF, Okapi BM25, and budgeted submodular selection (Lin & Bilmes, ACL 2011) [6].
  3. Clarification "System One Inference for Bounded Semantic Reasoning" (README.md Line 46): This is an original architectural concept (combining Kahneman's System 1 fast thinking with encoder models like microsoft/deberta-v3-base [7], Llama-Prompt-Guard-2 [8], and ModernBERT [9]), not a paper title.

Dimension 1: Prompt Compression Papers & Benchmarks

  • Verified (High) LLMLingua-2 (Pan et al., ACL Findings 2024): Formulates task-agnostic prompt compression as bidirectional encoder token classification ($p(\text{preserve})$) via GPT-4 data distillation [1].
  • Verified (High) Speedup & Latency Numbers: Achieves 3x–6x faster compression than perplexity-based methods and accelerates end-to-end latency by 1.6x–2.9x at 2x–5x compression ratios [2].
  • Verified (High) Prompt Compression Survey (Zongqian Li et al., 2024 / NAACL 2025): Establishes the canonical taxonomy dividing methods into hard prompt compression (discrete token removal) and soft prompt compression (continuous vectors) [3].

Dimension 2: Information-Theoretic & Query-Aware Pruning

  • Overturned as 0-Weight Selective Context (Yucheng Li et al., EMNLP 2023): Evaluates conditional self-information $I(x_t) = -\log_2 P(x_t \mid x_{<t})$ using a causal language model (GPT-2/OPT/LLaMA), whereas Tier 2's 0-weight engine computes static unigram self-information / IDF [4].
  • Overturned Attribution RECOMP (Fangyuan Xu et al., ICLR 2024): Uses trained contrastive dual-encoder and T5-Large compressors, not submodular chunk selection [5].
  • Verified (High) Lin & Bilmes (ACL-HLT 2011) & Okapi BM25 (Robertson & Zaragoza, 2009): Canonical foundations for budgeted monotone submodular extractive summarization with a $(1 - 1/e)$ greedy guarantee [6] and query-aware lexical scoring.

Dimension 3: System One Security Encoders

  • Verified (High) DeBERTaV3 (He, Gao, & Chen, ICLR 2023; microsoft/deberta-v3-base): Introduces Replaced Token Detection (RTD) with Gradient-Disentangled Embedding Sharing (GDES), achieving 91.37% on GLUE [7].
  • Verified (High) Meta Llama Prompt Guard 2: Provides meta-llama/Llama-Prompt-Guard-2-86M (mDeBERTa-v3-base) and meta-llama/Llama-Prompt-Guard-2-22M (DeBERTa-v3-xsmall, ~75% lower latency) for prompt-injection and jailbreak detection [8].
  • Verified (High) ModernBERT (Warner et al., Dec 2024): answerdotai/ModernBERT-base supports an 8,192-token context window with RoPE and GeGLU [9].

  • Verified (High) Rust candle-transformers Support: Natively implements bert, debertav2 (loads DeBERTa-v3 checkpoints), and modernbert [12].

Cross-Dimension Insights

  • 512-Token Window Limit on DeBERTa-v3 & BERT vs. 8,192 on ModernBERT: Both microsoft/deberta-v3-base [7] (and derivatives [8][10]) and bert-base-multilingual-cased [11] require $\le 512$-token chunking/striding in Tier 3, whereas ModernBERT supports 8,192 tokens natively [9].
  • Forge Decision Vindicated: Killing the "Shared-Backbone Multi-Head Model" in forged-idea.md is confirmed by incompatible tokenizers and backbones between DeBERTa-v3 (SentencePiece 128k) and LLMLingua-2 (WordPiece 119k / XLM-R 250k) [7][11].

Recommendations (Downstream Bindings)

  1. README.md & SPEC.md Default guard_model_id: Replace MoritzLaurer/DeBERTa-v3-xsmall-mnli-fever-anli-ling-wanli (404) with MoritzLaurer/deberta-v3-xsmall-zeroshot-v1.1-all-33, MoritzLaurer/DeBERTa-v3-xsmall-mnli-fever-anli-ling-binary, or MoritzLaurer/DeBERTa-v3-base-mnli-fever-anli [10].
  2. README.md Research Foundation Section: Cite He et al. (ICLR 2023, microsoft/deberta-v3-base) [7] and Lin & Bilmes (ACL 2011) [6], and clarify that Tier 2 is a 0-weight statistical approximation inspired by Selective Context [4] and RECOMP [5].
  3. SPEC.md Tier 3 Chunking Invariant: Enforce $\le 512$-token sentence-aligned chunking for DeBERTa-v3 and BERT checkpoints.
