## Findings (Claims)

1. **Claim:** *LLMLingua-2: Data Distillation for Efficient and Faithful Task-Agnostic Prompt Compression* (Pan et al., 2024) was published in *Findings of the Association for Computational Linguistics: ACL 2024* (pp. 963–981) and preprinted as `arXiv:2403.12968`.
   - **Source:** https://arxiv.org/abs/2403.12968 / https://aclanthology.org/2024.findings-acl.57/
   - **Publisher:** ACL Anthology / arXiv (Microsoft Corporation & Tsinghua University)
   - **Pub Date:** 2024-03 (arXiv) / 2024-08 (ACL Findings)
   - **Accessed:** 2026-10-21
   - **Confidence:** high
   - **Class:** canon / citation

2. **Claim:** LLMLingua-2 formulates task-agnostic prompt compression as a token classification problem ($p_{\text{preserve}}$ / keep-or-drop per token) using a bidirectional Transformer encoder (XLM-RoBERTa-large and mBERT) trained via data distillation from GPT-4, achieving 3x–6x faster compression than prior perplexity-based methods and accelerating end-to-end latency by 1.6x–2.9x at 2x–5x compression ratios.
   - **Source:** https://arxiv.org/abs/2403.12968
   - **Publisher:** arXiv / ACL Anthology
   - **Pub Date:** 2024-08
   - **Accessed:** 2026-10-21
   - **Confidence:** high
   - **Class:** benchmark

3. **Claim:** *Prompt Compression for Large Language Models: A Survey* by Zongqian Li, Yinhong Liu, Yixuan Su, and Nigel Collier (`arXiv:2410.12388`, Oct 2024; NAACL 2025) establishes the taxonomy dividing prompt compression into *hard prompt methods* (filtering/pruning discrete natural language tokens, e.g., Selective Context, LLMLingua) and *soft prompt methods* (compressing into continuous dense embedding vectors).
   - **Source:** https://arxiv.org/abs/2410.12388
   - **Publisher:** arXiv / ACL Anthology
   - **Pub Date:** 2024-10
   - **Accessed:** 2026-10-21
   - **Confidence:** high
   - **Class:** canon / taxonomy
